## 2026-01-18 - Проблема отображения GelPak на всех складах

**Проблема:**  
GelPak отображался для всех складов (Склад кристаллов, Склад пластин, Дальний склад), хотя должен показываться только для "Склада кристаллов".

**Подпроект:** telegram_bot_HMCB

**Влияние на другие подпроекты:**  
Нет

**Причина:**  
В коде отсутствовала проверка склада перед отображением остатков GelPak.

**Решение:**  
Добавлена проверка в `app.py` (строки 149-151):
```python
# GelPak показываем только для "Склад кристаллов"
if wh == "Склад кристаллов":
    response_parts.append(f"  Остаток GelPak: {stock_gp} шт.")
```

**Статус:** ✅ Решено

## 2026-01-18 - Ошибка 409: Конфликт токена бота

**Проблема:**  
Бот не работал из-за ошибки 409 "Conflict: terminated by other getUpdates request". Telegram API не мог обработать запросы, так как другой экземпляр бота уже использовал тот же токен.

**Подпроект:** telegram_bot_HMCB

**Влияние на другие подпроекты:**  
Нет

**Причина:**  
Другой экземпляр бота использовал тот же токен `TELEGRAM_BOT_TOKEN`. Возможные варианты:
- Бот запущен на другом сервере/компьютере
- Активный webhook от предыдущей конфигурации
- Скрытый процесс/служба

**Решение:**  
Изменен токен бота в `.env` файле на новый уникальный токен. Контейнер пересобран и перезапущен.

**Статус:** ✅ Решено

**Примечание:**  
Проверены все Docker-контейнеры в системе - все используют разные токены. Локальные процессы Python не запускают ботов. Проблема была решена сменой токена.
