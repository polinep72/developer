## Описание проекта

Telegram-бот для поиска остатков кристаллов в базе данных PostgreSQL. Бот позволяет пользователям искать кристаллы по шифру (полному или частичному) и показывает остатки по трем складам.

**Бот:** @HowManyCrystals_bot

## Назначение

Бот предназначен для быстрого поиска информации об остатках кристаллов на складах:
- Склад кристаллов (показывает остатки Wafer и GelPak)
- Склад пластин (не разделенные на кристаллы, показывает только остатки Wafer)
- Дальний склад (показывает только остатки Wafer)

## Функционал

### Команда /start
Отправляет приветственное сообщение с инструкцией по использованию бота.

### Поиск кристаллов
- Пользователь вводит шифр кристалла (полный или частичный)
- Бот выполняет SQL-запрос к базе данных PostgreSQL
- Возвращает остатки по каждому складу:
  - **Склад кристаллов:** остатки Wafer и GelPak
  - **Склад пластин:** остатки Wafer (GelPak не показывается)
  - **Дальний склад:** остатки Wafer (GelPak не показывается)

### SQL-запрос
Использует CTE (Common Table Expressions) для расчета остатков:
1. `income_union` - поступления (приход) со всех складов
2. `return_union` - возвраты со всех складов
3. `consumption_union` - расходование со всех складов
4. Расчет остатка: `приход + возврат - расход`

## Структура данных

### Таблицы базы данных
- `n_chip` - шифры кристаллов
- `invoice`, `invoice_p`, `invoice_f` - приходы по складам
- `consumption`, `consumption_p`, `consumption_f` - расходование по складам

### Склады
1. **Склад кристаллов** (invoice, consumption)
2. **Склад пластин** (invoice_p, consumption_p)
3. **Дальний склад** (invoice_f, consumption_f)
