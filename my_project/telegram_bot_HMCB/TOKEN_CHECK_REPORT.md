## Возможные причины ошибки 409

Ошибка 409 "Conflict: terminated by other getUpdates request" может возникать по следующим причинам:

### 1. Другой экземпляр на этом же компьютере
- ✅ Проверено: Локальные процессы Python не запускают ботов
- ⚠️ Возможно: Скрипт запущен вручную в другом окне терминала

### 2. Другой экземпляр на другом сервере/компьютере
- ⚠️ Требуется проверка: Другие компьютеры/серверы, где может быть запущен бот
- ⚠️ Проверить: Другие пользователи/процессы на том же сервере

### 3. Старый контейнер не был остановлен
- ✅ Проверено: Все контейнеры с ботом проверены - используются разные токены
- ✅ Контейнер `telegram_bot_hmcb-app-1` единственный с токеном `7305295549:...`

### 4. Бот запущен локально вне Docker
- ⚠️ Возможно: Прямой запуск `python app.py` в другом терминале
- ⚠️ Возможно: Запуск через планировщик задач Windows
- ⚠️ Возможно: Запуск как служба Windows

## Рекомендации для поиска дублирующего экземпляра

### 1. Проверить все терминалы и окна командной строки
```bash
# Проверить процессы python, которые запускают app.py
wmic process where "commandline like '%app.py%'" get processid,commandline
```

### 2. Проверить планировщик задач Windows
- Открыть "Планировщик заданий" (Task Scheduler)
- Найти задачи, запускающие `app.py` или бота

### 3. Проверить службы Windows
```powershell
Get-Service | Where-Object {$_.DisplayName -like "*telegram*" -or $_.DisplayName -like "*bot*"}
```

### 4. Проверить автозагрузку
- Проверить папку автозагрузки Windows
- Проверить реестр на наличие автозапуска

### 5. Проверить другие компьютеры/серверы
- Проверить другие серверы в сети 192.168.1.x
- Убедиться, что бот не запущен на других машинах

### 6. Проверить историю запусков Docker
```bash
docker ps -a --filter "name=hmcb" --format "{{.Names}} {{.Status}} {{.CreatedAt}}"
```
