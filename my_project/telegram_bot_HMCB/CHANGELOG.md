# Changelog

Все заметные изменения в проекте будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2026-01-18

### Added
- Первая рабочая версия Telegram-бота для поиска остатков кристаллов
- Команда `/start` для приветствия пользователей
- Поиск кристаллов по шифру (полному или частичному)
- Отображение остатков по трем складам:
  - Склад кристаллов (Wafer и GelPak)
  - Склад пластин (только Wafer)
  - Дальний склад (только Wafer)
- SQL-запрос для расчета остатков (приход + возврат - расход)
- Docker-контейнеризация проекта
- Конфигурация Docker Compose
- Загрузка переменных окружения из .env файла

### Changed
- GelPak показывается только для "Склада кристаллов" (изменение логики отображения)
- Обновлен токен бота для решения конфликта (ошибка 409)

### Fixed
- Исправлена ошибка 409 (конфликт токена) путем смены токена бота
- Корректное отображение остатков GelPak только для соответствующего склада

### Technical
- База образа: Python 3.9
- Сетевой режим: `host`
- Используется библиотека `telebot==0.0.5` (pyTelegramBotAPI)
