# SYNC_INSTRUCTIONS.md - Инструкции по синхронизации между компьютерами

## Обзор

Этот документ описывает процесс синхронизации проекта `telegram_bot_HMCB` между разными компьютерами и настройку рабочего окружения.

## Требования

- Git установлен и настроен
- Docker и Docker Compose установлены
- Python 3.9+ (для локальной разработки, опционально)
- Доступ к `.env` файлу с переменными окружения

## Первоначальная настройка на новом компьютере

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd my_project/telegram_bot_HMCB
```

### 2. Создание файла .env

Создайте файл `.env` в корне проекта со следующим содержимым:

```env
TELEGRAM_BOT_TOKEN=your_bot_token_here
DB_USER=postgres
DB_PASSWORD=your_password
DB_NAME=your_database_name
DB_HOST=192.168.1.139
DB_PORT=5432
```

**ВАЖНО:** Файл `.env` не должен быть закоммичен в Git (должен быть в `.gitignore`).

### 3. Чтение файлов контекста

Перед началом работы прочитайте следующие файлы для понимания проекта:

- `PROJECT_CONTEXT.md` - описание проекта, архитектура, компоненты
- `SOLUTIONS_HISTORY.md` - история решенных проблем и их решений
- `CHAT_HISTORY.md` - история переписки с AI-ассистентом
- `CHANGELOG.md` - история изменений проекта

### 4. Запуск Docker-контейнера

```bash
# Сборка образа
docker-compose build

# Запуск контейнера
docker-compose up -d

# Проверка статуса
docker ps --filter "name=telegram_bot_hmcb-app-1"

# Просмотр логов
docker logs telegram_bot_hmcb-app-1
```

## Рабочий процесс

### Перед началом работы

1. Прочитайте `PROJECT_CONTEXT.md` для понимания текущего состояния проекта
2. Прочитайте `SOLUTIONS_HISTORY.md` чтобы избежать повторения решенных проблем
3. Проверьте последние изменения в `CHANGELOG.md`

### Во время работы

1. Делайте коммиты с понятными сообщениями
2. Обновляйте `CHANGELOG.md` при значительных изменениях
3. Документируйте решенные проблемы в `SOLUTIONS_HISTORY.md`

### После завершения работы

1. Обновите версию в `CHANGELOG.md` (если необходимо)
2. Зафиксируйте изменения в Git
3. Обновите файлы контекста (PROJECT_CONTEXT.md, SOLUTIONS_HISTORY.md, CHAT_HISTORY.md)

## Синхронизация через Git

### Отправка изменений

```bash
git add .
git commit -m "Описание изменений"
git push origin <branch-name>
```

### Получение изменений

```bash
git pull origin <branch-name>
```

### После получения изменений

1. Обновите Docker-образ (если были изменения в Dockerfile или requirements.txt):
   ```bash
   docker-compose build --no-cache
   ```

2. Перезапустите контейнер:
   ```bash
   docker-compose down
   docker-compose up -d
   ```

## Обновление версии проекта

При внесении значительных изменений:

1. Обновите версию в `CHANGELOG.md` согласно Semantic Versioning:
   - **MAJOR** (X.0.0) - фундаментальные изменения
   - **MINOR** (0.X.0) - новый функционал
   - **PATCH** (0.0.X) - исправления ошибок

2. Обновите `PROJECT_CONTEXT.md` с новой версией и изменениями

3. Зафиксируйте изменения:
   ```bash
   git add .
   git commit -m "Версия X.Y.Z: Описание изменений"
   git tag vX.Y.Z
   git push origin <branch-name> --tags
   ```

## Решение проблем

### Контейнер не запускается

1. Проверьте `.env` файл - все переменные должны быть заданы
2. Проверьте логи: `docker logs telegram_bot_hmcb-app-1`
3. Проверьте подключение к базе данных: `ping DB_HOST`

### Ошибка 409 (конфликт токена)

1. Убедитесь, что токен уникален
2. Проверьте, не запущен ли бот на другом сервере/компьютере
3. Очистите webhook через Telegram API (если используется)

### Проблемы с синхронизацией Git

1. Проверьте статус: `git status`
2. Разрешите конфликты слияния вручную
3. После разрешения: `git add .` и `git commit`
