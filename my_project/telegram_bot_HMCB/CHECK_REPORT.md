# Отчет о проверке проекта telegram_bot_HMCB

**Дата проверки:** 2026-01-18  
**Проверяющий:** Cursor AI Assistant

## Статус проекта

### Структура проекта
- **app.py** - основной файл бота (170 строк)
- **Dockerfile** - конфигурация Docker-образа (Python 3.9)
- **docker-compose.yml** - конфигурация Docker Compose
- **requirements.txt** - зависимости проекта
- **__init__.py** - дополнительный файл (содержит другой бот)

### Назначение проекта
Telegram-бот для поиска остатков кристаллов в базе данных PostgreSQL. Бот позволяет искать кристаллы по шифру (полному или частичному) и показывает остатки по трем складам:
- Склад кристаллов
- Склад пластин (не разделенные на кристаллы)
- Дальний склад

### Функционал
1. Команда `/start` - приветствие и инструкция
2. Текстовый поиск - поиск кристаллов по шифру (ILIKE запрос)
3. Вывод остатков - показывает остатки Wafer и GelPak по каждому складу

### Обнаруженные проблемы

#### 1. Ошибка 409 - Конфликт экземпляров бота
**Тип:** `telebot.apihelper.ApiTelegramException`  
**Код:** 409  
**Описание:** "Conflict: terminated by other getUpdates request; make sure that only one bot instance is running"

**Причина:**
- Запущено несколько экземпляров бота с одним токеном `TELEGRAM_BOT_TOKEN`
- Возможные варианты:
  1. Бот запущен вне Docker (локальный процесс)
  2. Другой контейнер использует тот же токен
  3. На другом сервере/компьютере запущен экземпляр с тем же токеном

**Последствия:**
- Бот не может получать обновления от Telegram API
- Функционал бота не работает
- В логах постоянно появляются ошибки каждые 10-30 секунд

**Рекомендации:**
1. ✅ **НАЙДЕНО:** Запущены процессы Python вне Docker:
   - PID 2120 (python.exe)
   - PID 7100 (python.exe)
   **Действие:** Проверить, не запущен ли один из них как бот. Если да - остановить.
2. Проверить другие контейнеры на использование того же токена
3. Убедиться, что бот запущен только в одном месте
4. Если бот должен работать на нескольких серверах - использовать webhook вместо polling
