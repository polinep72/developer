## [0.3.9] - 2026-02-17

### Изменено
- Улучшен интерфейс страницы «База данных»:
  - Поле поиска перемещено справа от кнопок вкладок (Кристаллы, Корпуса, Крышки, Вид работ)
  - Ширина поля поиска установлена в 370px для полного отображения плейсхолдеров
  - Шапки таблиц на всех подвкладках унифицированы: тёмно-синий фон (#34495e), белый текст, скруглённые верхние углы
  - Кнопки «Изменить» и «Удалить» в таблице «Вид работ» приведены к единому стилю с кнопкой «Сохранить» на других подвкладках (без собственных границ, внутри ячейки)
  - Исправлено вертикальное выравнивание кнопок действий: они центрируются по высоте строки через inline-flex контейнер

### Исправлено
- Устранена проблема с отображением границ у кнопок «Изменить»/«Удалить» в таблице «Вид работ»
- Исправлено вертикальное выравнивание кнопок действий в строках с многострочным текстом

## [0.3.8] - 2026-02-09

### Добавлено
- Таблицы и миграции для корпусов/крышек и размеров: `size_body`, `size_cover`, `bodies.material/body_cost/run_norm`, `covers.material/body_cost/run_norm`, `body_cover_options`.
- **BOM:** двухшаговый выбор (тип: Корпус/Крышка/Кристалл → модель по данным `elements`/`bodies`/`covers`/`chips`), API `/api/bom-options/types` и `/api/bom-options/models`.
- Импорт материалов корпусов/крышек из Excel: `scripts/import_organic_bodies_covers_from_excel.py` + файл `materials_organic_bodies_covers_2025_06_16.xls`.
- Связь корпусов/крышек с первичным справочником `tlvsh_serial_numbers` через `serial_id` и скрипт `scripts/link_bodies_covers_to_serial_numbers.py`.
- Таблица `body_cover_options` для связи один‑ко‑многим между корпусами и допустимыми крышками.

### Исправлено
- Обновлены внешние ключи `element_bom` для работы с таблицей `elements` (вместо устаревшей `elements_legacy`), устранена ошибка FK при добавлении строк состава.
- Исправлен вывод типа в таблице BOM (отображаются русские «Корпус/Крышка/Кристалл» вместо кодов `body/cover/chip`).
- Добавлены миграции до финальной структуры `size_body` (убран `size_name`, добавлены `created_at/updated_at`).

## [0.3.0] - 2024

### Добавлено
- Нормализованная структура БД:
  - Таблица `типы_элементов` - справочник типов элементов
  - Таблица `элементы` - объединенная таблица всех элементов
  - Таблица `состав_элементов` - BOM (Bill of Materials)
- Модели для нормализованной структуры:
  - `ТипЭлемента`, `Элемент`, `СоставЭлементов`
  - Обновлены связи в `Трудозатрата`, `Калькуляция`, `ПротоколЦены`
- API endpoints для элементов:
  - `GET /api/elements/` - список элементов с фильтрацией
  - `GET /api/elements/types` - список типов элементов
  - `GET /api/elements/{id}` - получить элемент
  - `GET /api/elements/{id}/composition` - получить состав элемента
  - `POST /api/elements/{id}/composition` - добавить элемент в состав
- Frontend страницы:
  - `Elements.jsx` - список элементов с фильтрацией и поиском
  - `ElementDetail.jsx` - детальная информация об элементе и его составе
- Скрипт миграции `scripts/migrate_from_warehouse.py`
- Документация: `DATABASE_DESIGN.md`, `MIGRATION_GUIDE.md`

## [0.1.0] - 2024

### Добавлено
- Начальный анализ существующей системы расчета себестоимости

### Описание
Первая версия проекта включает полный анализ существующей Excel-системы с VBA макросами для расчета себестоимости и ценообразования продукции. Документирована вся бизнес-логика, структура данных и алгоритмы расчетов. Подготовлена основа для разработки веб-портала.
